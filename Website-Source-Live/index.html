Why it exists

Built because everything else was half-baked.

I built Camera Zapper for my own Macs because the sync apps out there were incomplete, awkward, or tied to a single destination. Private by design

Your media stays yours.

  • Private-only uploads. Camera Zapper can't accidentally publish a YouTube video or a Flickr photo, and it never creates a shared Google Photos link.
  • Safe by default. Source deletion stays blocked until every service you mark required has verified that exact file.
  • No personal defaults. Fresh installs ship with no device names, hostnames, or paths — just a local archive at ~/Pictures/Camera Zapper/Archive, with NAS and cloud disabled until you turn them on.
  • No telemetry. Nothing phones home. No analytics, no data sold — ever.

Install & Android setup

Up and running in a couple of minutes.

  1. Open Zebtron-Camera-Zapper-1.349.dmg and drag Zebtron Camera Zapper into Applications.
  2. Control-click the app → Open the first time; approve the Photos / removable-media / folder / automation prompts.
  3. For Android: install ADB with brew install android-platform-tools, enable USB debugging, connect, and choose Probe Again. (ADB handles detection, listing, on-device hashing, transfer, and confirmed deletion.)
  4. Enable only the destinations you actually use, and leave automatic deletion off until several manual runs check out.

Setting up destinations: version 1.349 includes a seven-step Setup Wizard. Choose only the services you use, test each destination, decide which must succeed before deletion, and arrange their priority. Unselected services stay quietly marked Not set up. Settings can be exported for another Mac or upgrade; passwords, API secrets, OAuth tokens, and Keychain data are never included.
